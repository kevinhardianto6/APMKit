## What went wrong / worth remembering

- The anti-loop flag in the first feat-005 review pass was correctly identified but under-
  fixed: documenting the manual step wasn't enough per the user ("if an integrator has to
  remember a manual step... that's a design defect"). The fix that satisfied it wasn't more
  documentation, it was removing the possibility of forgetting — a required parameter instead
  of a default, and one shared value type instead of two independently-configured ones. Worth
  applying this standard proactively to future safety-critical wiring (kill switch, remote
  config) rather than waiting to be told.
- Apple's `Compression` framework has no direct gzip API — `COMPRESSION_ZLIB` via the C buffer
  functions is raw DEFLATE, not zlib or gzip framing. Confirmed via a hand-rolled RFC 1952
  gzip encoder + a from-scratch test-only gunzip for round-trip verification.
- `Data` subsequences aren't guaranteed 4-byte aligned — `.load(as: UInt32.self)` on a `Data`
  slice can crash with "misaligned raw pointer." Use manual byte assembly instead of raw
  pointer loads on arbitrary `Data` slices.
