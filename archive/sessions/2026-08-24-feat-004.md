  claiming them done — this is exactly the flagging behavior that let the user make an

  implemented" or "done."

  the user formalizing later, same pattern as `MOB-02b` for http_error.

  was small, directed, and the archive file was updated to point at where the amendment
  happened rather than silently letting the archived record go stale/inaccurate.
