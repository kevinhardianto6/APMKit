## What went wrong / worth remembering

- The harness auto-scaffold defaulted to an Xcode framework project (`.xcodeproj`,
  deployment target = whatever the local Xcode version defaults to). The spec wanted SPM.
  Caught before any code was written by asking the user rather than guessing — worth checking
  spec deliverable shape against harness auto-detection before building on top of it.
- `swift test` runs against the host macOS toolchain by default, not an iOS Simulator.
  `DeviceInfo.current()` needed a `#if canImport(UIKit)` fallback branch to keep compiling on
  macOS. Flagged in `CONSTITUTION.md`/`AGENTS.md` as a recurring concern for later features
  (feat-007 UIKit lifecycle notifications, feat-008 simulator/jailbreak checks) — may need to
  switch `verify.sh` to `xcodebuild test -destination 'platform=iOS Simulator,...'` once a
  feature can't compile on macOS at all even with `#if` guards.
